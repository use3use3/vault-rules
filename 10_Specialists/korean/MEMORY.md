# korean（韓国語）Memory

## 学習の目的

**主目的: K-POPアイドルの発話を字幕なしで理解できるようになること。**

- YouTubeのVlog
- Weverse の投稿・動画
- LIVE配信でのトーク

**学習方法の主軸は「動画学習」。** 教材を机に向かって進めるスタイルではない。

**副目的**

- 韓国旅行での実用会話（行きたいと考えている）
- 韓国ドラマの理解

**したがって重点は「韓国国内の日常会話と若者言葉」。** 教科書的な整った韓国語よりも、実際に話されている口語が対象。

## 現在の状況（2026-07-26 時点）

**レベル: 初心者。ただし偏りがある。**

| 項目 | 状態 |
| :---- | :---- |
| 音の聞き取り | **なんとなくできる**（長年聞いてきた耳がある） |
| 語彙 | **足りない ← 最大のボトルネック** |
| 文法 | あまり分かっていない |
| ハングルの読み書き | 未確認 |

**この偏りが設計上いちばん重要。** 音は拾えているので、**語彙が入れば即座に理解に変わる**状態。したがって解説は「語彙を確実に残すこと」に重点を置く。文法の体系的な講義よりも、出てきた語を1つずつ確実に蓄積するほうが効く。
